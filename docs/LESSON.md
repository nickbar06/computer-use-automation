# Lesson

An agent is a **loop**: observe the screen, ask a model for one action, execute it, repeat. This take-home then **compiles** a successful loop into JSON and **replays** it without the model.

Specs live in [`../tasks/`](../tasks/README.md) (`00-orientation.md`, `01-scaffold.md`, …), not in this file.

If a slice is confusing, re-read that task’s “Why this exists” before adding more code. Background links are in [LEARN.md](LEARN.md).
